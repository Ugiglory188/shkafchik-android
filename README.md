# Шкафчик — Android

Android WebView-проект приложения «Шкафчик». В `app/src/main/assets/index.html` находится последняя HTML-версия 2.7.9.

## Включено
- Последняя версия интерфейса: папки, заметки, календарь и события.
- Фирменная иконка: тёмно-синий шкафчик с двумя ящиками.
- Android-мост для показа уведомлений.
- Системный выбор файлов для вложений и импорта резервной копии.
- Сохранение JSON-резервной копии через системный диалог «Сохранить как».
- Сборка отладочного APK через GitHub Actions.

## Пока не реализовано
- Надёжные напоминания после принудительного закрытия приложения и перезагрузки телефона.
- Полноценный музыкальный плеер с фоновым сервисом, MediaStore и MediaSession.
- Автоматический перенос данных из предыдущего APK.

## Сборка
Отправь изменения в `main` или запусти workflow `Build Shkafchik APK` вручную. Готовый APK появится в Artifacts.

**Важно:** перед установкой новой версии сохрани резервную копию из старого приложения. Не загружай личные JSON-копии в GitHub.
